# Football Club Architect Data Model

## GameState

`GameState` はローカルMVPの単一状態です。
ターン、行動ポイント、クラブ指標、スタッフ、ログ、財務ログ、試合レポートを保持します。

## StaffMember

スタッフは能力、性格、不満、AI精度、委任レベル、給与、忠誠心、成長余地を持ちます。
今後のPhaseで、能力とAI精度に応じた行動選択を追加します。

## MatchReport

試合後レポートは、結果だけでなく敗因、良かった点、改善提案を保持します。
プレイヤーが次の経営判断をしやすくするための情報源です。
