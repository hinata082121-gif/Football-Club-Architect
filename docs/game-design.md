# Football Club Architect Game Design

## 概要

Football Club Architect は、AIで創る名門クラブをテーマにしたAIクラブ経営シミュレーションです。
プレイヤーはサッカークラブの社長です。
監督として試合中の采配を行うのではなく、クラブ経営者として資金、人材、ファン、評判、チーム戦力、スタッフ、監督、試合、大会、練習試合を管理します。

## 中核体験

- 最初は社長が自分で業務を行う
- クラブが成長すると業務が増え、社長一人では対応できなくなる
- スタッフを雇い、業務をAIに委任する
- スタッフAIの能力と性格によって行動の質が変わる
- AIの判断には理由と結果のログが残る
- 重大な行動はAIが勝手に実行せず、社長の承認を必要とする

## 選手システムの方向性

選手システムでは、社長は補強予算、重点ポジション、若手重視か即戦力重視かの方針、獲得・放出の最終承認を担当します。
監督AIはスタメン、ベンチ、起用方針、若手起用を判断し、スカウトAIは候補選手の発掘、能力推定、将来性推定、リスク評価を行います。

選手には年齢、総合能力、将来性、成長、コンディション、士気、年俸、契約月数を持たせ、成長・衰退・引退によって戦力が循環する設計にします。
詳細は [player-system-design.md](./player-system-design.md) を参照してください。

## 財務リカバリーの方向性

クラブ資金が悪化した場合は、即ゲームオーバーではなく、警告、改善提案、短期リカバリー、融資、スポンサー前借り、選手売却、人件費削減、再建計画を段階的に提示します。

債務超過は経営判断に重みを持たせるために導入しますが、猶予期間と最終救済策を設け、プレイヤーが立て直し判断を行える設計にします。
詳細は [financial-recovery-design.md](./financial-recovery-design.md) を参照してください。

## MVP方針

複雑な市場、オンライン、認証、DBは後回しにし、ローカル状態でターン制の経営サイクルを検証します。
