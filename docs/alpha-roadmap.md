# Football Club Architect Alpha Roadmap

## 目的

MVPで確認した社長行動、スタッフAI、試合、練習試合、イベント、記録画面を土台に、α版ではクラブ経営の継続性を高めます。

## 主要テーマ

1. 選手システム
2. スカウト候補と獲得承認
3. チーム編成画面
4. 監督への起用委託
5. 年齢、成長、衰退、契約管理
6. 財務リカバリーと債務超過
7. シーズン制と大会管理
8. 疑似他プレイヤークラブの拡張

## 選手システム導入順

### Phase A: 軽量Player導入

- `Player` 型を追加する
- 初期所属選手を生成する
- チーム編成画面に一覧を表示する
- 既存の `club.teamPower` と同期する

### Phase B: スカウト候補

- スカウトAIが候補選手を生成する
- 候補の推定能力、推定将来性、年俸、リスクを表示する
- 高額契約は承認制にする

### Phase C: チーム戦力算出

- 所属選手と起用状態からチーム戦力を算出する
- 監督AIの起用方針を反映する
- 練習試合経験を若手成長に接続する

### Phase D: 年齢と契約

- 年齢進行、成長、衰退を実装する
- 契約残り月数と年俸総額を管理する
- 放出候補と契約更新方針を追加する

### Phase E: 財務リカバリー

- 財務状態ランクを追加する
- 融資、スポンサー前借り、選手売却導線を追加する
- 債務超過の猶予カウントを実装する
- 経営破綻または縮小再建の選択肢を追加する

詳細設計は [player-system-design.md](./player-system-design.md) を参照してください。
財務リカバリーの詳細設計は [financial-recovery-design.md](./financial-recovery-design.md) を参照してください。
