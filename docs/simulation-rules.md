# Football Club Architect Simulation Rules

## ターン

各ターン開始時に社長の行動ポイントが回復します。
スタッフAIの自動行動、ランダムイベント、月次財務処理は今後のPhaseで追加します。

## スタッフAI

能力が高いスタッフほど、状況に合った効果的な行動を選びやすくなります。
能力が低いスタッフは効果が小さい行動や状況に合わない行動を選びやすい一方、安い、成長余地がある、忠誠心が高いなどの利点を持てます。

## 試合

試合は完全自動進行です。
結果にはチーム戦力、監督レベル、コンディション、戦術、ホーム補正、運が影響する予定です。

## 練習試合

公式大会に参加できない場合の救済制度です。
選手経験値、監督経験値、戦術理解、チーム連携、少額収入、ファン微増を得られるようにします。
